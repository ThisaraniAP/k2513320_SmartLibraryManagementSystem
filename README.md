# Smart Library Management System with Java
Developed a Smart Library Management System (SLMS) using Java, applying advanced Object-Oriented Programming principles and design patterns to build a scalable and maintainable library solution.  The project focused on implementing real-world library operations, including borrowing, reservations, fine calculation, and automated notifications.

Key Features:
-	OOP & Design Patterns: Applied Observer, Strategy, State, Builder, Decorator, and Command patterns to ensure flexibility and modular design.
-	Book & User Management: Managed books, users, and borrowing history with role-based rules for Students, Faculty, and Guests.
-	Borrowing & Reservations: Implemented borrowing limits, due dates, reservation handling, and availability tracking.
-	Fine Calculation: Used Strategy pattern to calculate fines based on membership type.
-	Notifications System: Automated alerts for due dates, overdue books, and reserved book availability using Observer pattern.
-	Reports & Testing: Generated reports and validated system functionality through comprehensive test cases.

This project strengthened skills in Java, object-oriented design, design patterns, and building complex, real-world systems.
